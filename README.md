## Gerenciador de Tarefas - Back-End
Este projeto é um sistema de gerenciamento de tarefas desenvolvido com Node.js, utilizando o Prisma como ORM e MySQL como banco de dados. Ele fornece uma API para gerenciar tarefas, incluindo operações de criação, leitura, atualização e exclusão (CRUD).

## Tecnologias Utilizadas
- Node.js: Ambiente de execução JavaScript no lado do servidor.
- Prisma: ORM para interagir com o banco de dados.
- MySQL: Sistema de gerenciamento de banco de dados relacional.
- Express.js: Framework para construção de APIs RESTful.
- Dotenv: Gerenciamento de variáveis de ambiente.
